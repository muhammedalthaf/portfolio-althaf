# Project Thumbnail Prompts — Nano Banana (AI Studio)

**How to use:**
1. Open [aistudio.google.com](https://aistudio.google.com) → new chat → pick the image model (Nano Banana / "gemini-3.1-flash-image" or newest available)
2. Paste one prompt per generation. Set aspect ratio **16:9** if the UI offers it (otherwise it's in the prompt)
3. Download each PNG and save into the `images/` folder with the **exact filename** listed
4. Tell Claude when files are in — everything after that (optimization + wiring into cards + deploy) is automated

**Style base (already embedded in every prompt):** dark navy `#0a0a0f` background, neon cyan `#00d4ff` + purple `#7c3aed` glow, isometric 3D, subtle grid, no text.
